## What carries over

- **Reading code.** When an alert points at an API endpoint, I've written endpoints like it.
- **Knowing the pipeline.** CI/CD, Docker, Kubernetes, Terraform. I know where a security gate is supposed to go.
- **GenAI.** I've built LLM apps, so I've seen where they're fragile: prompt injection, data leaks, over-trusting output.
